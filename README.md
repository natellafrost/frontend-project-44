## Использование

После установки доступны три игры. Запускаются из любой директории.

### Brain Games — приветствие

```bash
brain-games
```

### Brain Even — проверка числа на чётность

Нужно ответить `yes`, если число чётное, иначе `no`. Три правильных ответа подряд — победа.

```bash
brain-even
```

[![asciicast](https://asciinema.org/a/996emcVgknU8l7re.svg)](https://asciinema.org/a/996emcVgknU8l7re)

### Brain Calc — калькулятор

Нужно вычислить результат выражения (`+`, `-`, `*`). Три правильных ответа подряд — победа.

```bash
brain-calc
```

[![asciicast](https://asciinema.org/a/LBQNoigrbDcCFsCj.svg)](https://asciinema.org/a/LBQNoigrbDcCFsCj)

### Brain GCD — наибольший общий делитель

Нужно найти НОД двух чисел. Три правильных ответа подряд — победа.

```bash
brain-gcd
```

[![asciicast](https://asciinema.org/a/2SmKAnJoNi0i6ItC.svg)](https://asciinema.org/a/2SmKAnJoNi0i6ItC)

### Brain Progression — арифметическая прогрессия

Нужно определить число, скрытое за `..` в арифметической прогрессии. Три правильных ответа подряд — победа.

```bash
brain-progression
```

[![asciicast](https://asciinema.org/a/OzJCsX77GrvpEDvo.svg)](https://asciinema.org/a/OzJCsX77GrvpEDvo)

### Brain Prime — простое ли число

Нужно ответить `yes`, если число простое, иначе `no`. Три правильных ответа подряд — победа.

```bash
brain-prime
```

[![asciicast](https://asciinema.org/a/zLtrsGhTLEV9Y0jb.svg)](https://asciinema.org/a/zLtrsGhTLEV9Y0jb)
